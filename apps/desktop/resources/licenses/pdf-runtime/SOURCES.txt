Components: PyMuPDF 1.28.2 and MuPDF 1.28.2 (Artifex Software).
The upstream PyMuPDF package metadata states:
Dual Licensed - GNU AFFERO GPL 3.0 or Artifex Commercial License
This release supplies the public open-source license materials. No commercial
license grant is asserted here. PyMuPDF src/__init__.py also carries the upstream
SPDX-License-Identifier: GPL-3.0-only header; it is preserved in the source archive.

Files beside this notice:
- PyMuPDF-COPYING.txt: the original short COPYING shipped in the upstream wheel.
- PyMuPDF-BUILD.txt: the upstream wheel's original pymupdf/_build.py provenance.
- AGPL-3.0.txt: complete license, copied unchanged from PyMuPDF's source COPYING
  (also identical to MuPDF's root COPYING).
- GPL-3.0.txt: complete license, copied unchanged from MuPDF source file
  thirdparty/lcms2/plugins/threaded/COPYING.GPL3.
- MuPDF-NOTICE.txt: the unchanged upstream MuPDF README, including copyright.
- THIRD-PARTY-NOTICES.txt: upstream license/copyright/notice files from the MuPDF
  source, including font notices, FreeType licenses, and libjpeg's README.
  Line endings and trailing whitespace in this combined file are normalized.
  Optional third-party components are included for notice preservation; this
  listing does not assert that each optional feature is enabled in the wheel.

The following two archives are unmodified upstream source distributions. They
retain the source-file copyright headers, third-party source and notices, and
upstream build scripts. PyMuPDF's sdist does NOT embed the MuPDF source archive;
both downloads are needed for the source set supplied with this release.

The macOS packaging script pins PyMuPDF==1.28.2 from PyPI and includes its Python
module, native MuPDF libraries, wheel metadata, and these license materials in
the PyInstaller runtime. It does not patch the upstream PDF runtime source.
The formal packaging environment is Apple Silicon macOS, arm64 Python 3.11,
JDK 21, PyInstaller 6.16.0 and the additional versions pinned in that script.
From apps/desktop, install the lockfile dependencies with npm ci; the package
scripts prepare:mac, dist:mac:internal and dist:mac contain the build commands
and the script checks report the required local toolchain. Upstream setup.py
contains the source build steps and environment options for PyMuPDF; MuPDF's
Makefile and scripts/mupdfwrap.py contain its native-library/bindings build steps.

The Windows x64 packaging script also pins PyMuPDF==1.28.2 and preserves these
source and license materials. It builds the runtime on Windows using x64
Python 3.11, JDK 21 and the versions in platforms/windows/runtime-dependencies.json.
From the repository root, install desktop dependencies with npm ci --prefix
apps/desktop, then run npm run build:windows to produce the NSIS installer and ZIP.
